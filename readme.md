# Sistema Colegio - Versión 2.0

Este repositorio contiene la reestructuración completa del proyecto del colegio.

## Estructura del Proyecto
- `/backend`: API REST construida en Node.js, Express y PostgreSQL (Dockerizada).
- `/frontend`: Interfaz de usuario desarrollada en React.
- `/legado_v1`: Archivo del código inicial desarrollado previamente a modo de prueba/histórico.

## Historia del Proyecto
- **Versión 1.0 (2025):** Monolito básico desarrollado durante la primera etapa de aprendizaje.
- **Versión 2.0 (Actual):** Arquitectura cliente-servidor desacoplada con contenedorización en Docker y base de datos optimizada.
